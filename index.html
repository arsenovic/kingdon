Kingdon — Pythonic Geometric Algebra Package#

Features#

Kingdon is a Geometric Algebra (GA) library which combines a Pythonic API with symbolic simplification and just-in-time compilation to achieve high-performance in a single package.

  • Symbolically optimized code generation

  • Leverages sparseness of input

  • Symbolic and numerical GA computations

  • ganja.js graphics in jupyter notebooks

  • Coefficients over numpy, torch, sympy, or anything with +, -, *

  • Automatic broadcasting, e.g. over point-clouds

  • Compatible with einops via kingdon.einops_backend

  • Compatible with numba and other JIT compilers

Code Example#

>>> from kingdon import Algebra
>>> alg = Algebra(3, 0, 1)
>>> globals().update(alg.blades)
>>> b = 2 * e12
>>> v = 3 * e1
>>> b * v
-6 𝐞₂
