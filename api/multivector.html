kingdon.multivector#

The MultiVector and its predefined types, such as the k-vectors and the PGA types.

Multivectors#

MultiVector

MultiVectorType

MultiVector type allows typehinting for MultiVectors of a given shape.

Shape

The shape of a multivector: the plain tuple of its array dimensions, which additionally knows the multivector type it describes so that it can say so when printed.

k-vectors#

KVector

Baseclass for k-vectors.

Scalar

Type of scalars (grade 0).

Vector

Type of vectors (grade 1).

Bivector

Type of bivectors (grade 2).

Trivector

Type of trivectors (grade 3).

Quadvector

Type of quadvectors (grade 4).

Pentavector

Type of pentavectors (grade 5).

Hexavector

Type of hexavectors (grade 6).

Heptavector

Type of heptavectors (grade 7).

Octovector

Type of octovectors (grade 8).

Compositions#

Bireflection

A bireflection \(R\) is assumed to be identical to \(\mathbf{R} = p \widetilde{q}\) with \(p\) and \(q\) normalized vectors, such that \(R \widetilde{R} = 1\).
