CompiledExpression#

class kingdon.codegen.CompiledExpression(algebra: Algebra, keys_out: tuple[int], func: Callable, mvtype: MultiVectorType, output_mv_idx: int | None = None, wrapped_func: Callable | None = None, values_asarray: Callable | None = None)[source]#

Bases: NamedTuple

Output of a codegen function.

Parameters:

  • keys_out – tuple with the output blades in binary rep.

  • func – callable that takes (several) sequence(s) of values returns a tuple of len(keys_out).

  • wrapped_func – decorated func if a wrapper was provided, else identical to func.

  • mvtype – type of the output multivector. Defaults to MultiVector.
