OperatorDict#

class kingdon.operator_dict.OperatorDict(name: str, codegen: Callable, algebra: Algebra, codegen_symbolcls: Callable = None, lambdifier: Callable = None, lambdifier_kwargs: dict = <factory>, wrapper: Callable = None, values_asarray: Callable = None)[source]#

Bases: Mapping

A dict-like object which performs codegen of a particular operator, and caches the result for future use. For example, to generate the geometric product, we create an OperatorDict as follows:

import kingdon.operators as ops
alg = Algebra(3, 0, 1)
gp = OperatorDict('gp', codegen=ops.gp, algebra=alg)

Here, ops.gp is a function that takes two symbolic MultiVector as input and outputs a single MultiVector.
