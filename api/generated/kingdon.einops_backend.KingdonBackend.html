concat(mvs: list[MultiVector], axis: int) → MultiVector[source]#

Concatenate mvs along axis, used by einops.pack().

All multivectors must be of the same type, since it is the type that gives the blades their meaning, but they need not have the same keys: the result has the union of the keys of mvs, and a blade that an input does not have contributes zeros. So a sparse input is densified to the keys of the result, e.g. packing an alg.vector(e1=...) with an alg.vector(...) gives the former an explicit zero on e2.

einsum(pattern, *operands)[source]#

Einstein summation over the array dimensions of multivectors, e.g. einsum(vec, weight, 'i, i j -> j'). The blade axis is implicit: patterns describe mv.shape only, and the summation is performed blade by blade. Consequently all multivector operands must have the same keys, with the exception of scalars, which multiply every blade.

to_numpy(x: MultiVector) → MultiVector[source]#

Convert the coefficients of x to numpy arrays.

Unlike the other backends this returns a multivector, not an numpy.ndarray, since a multivector is a container of tensors rather than a tensor itself. Use mv.values() on the result to get at the raw array.
