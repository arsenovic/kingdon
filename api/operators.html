kingdon.operators#

Built-in geometric operators, such as the geometric product, wedge product, sandwich, inverse, etc.

These functions are assumed to operate on multivectors, and return a multivector.

These functions are also what the multivector types use to define their layouts, see Type system.

Products#

product

Helper function for the codegen of all product-type functions.

gp

Generate the geometric product between x and y.

sw

Generate the conjugation of y by the versor (k-reflection) x, using the conjugation formula \((-1)^{k \ell} x y x^{-1}\), where \(k\) is the grade of x and \(\ell\) is the grade of the blade y.

cp

Generate the commutator product of x and y: x.cp(y) = 0.5*(x*y-y*x).

acp

Generate the anti-commutator product of x and y: x.acp(y) = 0.5*(x*y+y*x).

ip

Generate the inner product of x and y.

lc

Generate the left-contraction of x and y.

rc

Generate the right-contraction of x and y.

sp

Generate the scalar product of x and y.

proj

Generate the projection of x onto y: \((x \cdot y) \widetilde{y}\), where it is assumed that y is a normalized versor (k-reflection) and hence \(y^{-1} = \widetilde{y}\).

op

Generate the outer product of x and y: x.op(y) = x ^ y.

rp

Generate the regressive product of x and y:, \(x \vee y\).

square

Generate the geometric square of x using one symbolic operand.

Sums#

add

Sum \(x + y\).

sub

Difference \(x - y\).

neg

Negation \(-x\).

Involutions#

involutions

Codegen for the involutions of Clifford algebras: reverse, grade involute, and Clifford involution.

reverse

Reversion \(\widetilde{x}\).

involute

Main grade involution.

conjugate

Clifford conjugation: involution and reversion combined.

grade

Select grade g part of x.

Norms and roots#

normsq

Squared norm \(x \widetilde{x}\).

sqrt

Take the square root using the study number approach as described in https://doi.org/10.1002/mma.8639

Inverses and division#

inv

Inverse of y.

hitzer_inv

Generate code for the inverse of x using the Hitzer inverse, which works up to 5D algebras.

shirokov_inv

Generate code for the inverse of x using the Shirokov inverse, which is works in any algebra, but it can be expensive to compute.

div

Generate code for \(x y^{-1}\).

Fraction

Tuple representing a fraction.

Duals#

polarity

Polarity dual: x multiplied by the inverse pseudoscalar from the right.

unpolarity

Inverse of polarity().

hodge

Hodge dual: map each basis blade of x to its complement.

unhodge

Inverse of hodge().

Outer functions#

outerexp

Outer exponential: \(1 + x + \tfrac{1}{2!} x \wedge x + \ldots\), which ends once the next term is zero.

outersin

Outer sine: the odd terms of outerexp().

outercos

Outer cosine: the even terms of outerexp().

outertan

Outer tangent: outersin() divided by outercos().

Helpers#

is_zero

True only for values which are certainly zero, i.e. scalar zeros and symbolic expressions that cancelled exactly.

dict_to_multivector

Make a multivector out of a {key: value} dict, dropping the values that are certainly zero.

scalar

Scalar multivector of algebra with coefficient value.
